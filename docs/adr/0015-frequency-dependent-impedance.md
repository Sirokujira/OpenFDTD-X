# ADR-0015: FDTD の帯域内の周波数依存インピーダンス

## Status

Accepted (2026-11-08) — ソルバー側 (OpenAcoustics の `ofdx_acoustic_fdtd`) は
実装・検証済み (OpenAcoustics PR #9、検証 (p))。GUI 側の設定 UI
(AcousticSolverTab のトグル → `AcousticOpts::frequencyDependentImpedance` →
`.ofdx` `acoustic.frequency_dependent_impedance`) も実装済み (既定のままなら
キー自体を書かない — 絶対規則 2。selftest `fdimp-ofdx:` がバイト一致往復を
検証する)。**本 ADR に未実装の項目は無い。**

## Context

- AcousticTab の吸音表は 6 バンド (125 Hz〜4 kHz) の α を持つ。幾何音響
  ソルバーはそれをバンド別に使うが、FDTD ソルバーは有効帯域 [0, fmax]
  (fmax = c/(10·dx)) と重なるオクターブバンドの**平均 1 値**で境界の実
  インピーダンスを作っていた (OpenAcoustics の不変条件 3b)。
- 室規模の格子 (dx = 0.05〜0.1 m) では帯域内に 2〜3 バンドが入り、そこで
  α が大きく変わる材料 (多孔質材は高域ほど吸音、板振動は低域ほど吸音) では
  平均 1 値がどのバンドにも合わない (例: [0.2, 0.35, 0.6] の平均 0.383 は
  125 Hz の |R| を −12% ずらす)。ADR-0011 の Consequences で「帯域内で Z を
  周波数依存にするには境界のデジタルフィルタ (受動性の保証を含む) が要り、
  別途判断する」としていた項目である。

## Decision

1. **`.ofdx` に `acoustic.frequency_dependent_impedance` (bool、既定 false)
   を新設する。** false = 従来どおり帯域内平均の 1 値 (完全後方互換 —
   既存入力の結果は 1 bit も変わらない)。
2. **true の境界モデルは受動 1 次素子**: 規格化インピーダンスを
   ζ(ω) = r + k/(iω) (剛性型 — α が高域ほど大きい) または r + iωm
   (質量型 — 高域ほど小さい) にし、有効帯域内の**最低・最高バンドの中心で
   |R| = √(1−α_b) に厳密に**合わせる (α は従来どおり垂直入射として読む)。
   中間バンドは 1 次素子の近似で、目標値とモデル値を solver.log に出す。
   2 次以上のフィルタ (全バンドに合わせる) は受動性の保証が難しく、範囲外。
3. **離散化は無条件に受動**: 剛性は面ごとの変位の状態 (台形則)、質量は
   半セルの質量への加算。双一次変換なので安定性の条件を増やさない。
   周波数は事前ワープ ω~ = (2/dt)tan(ω dt/2) で合わせる (離散境界が
   バンド中心で厳密に合う)。
4. **正直なフォールバック**: 帯域内のバンドが同値・1 バンドだけ
   (fmax < 177 Hz、dx > 0.19 m)・剛体は従来とビット一致。1 次素子で表せない
   急な変化 (例: 1 オクターブ半で 0.3 → 0.9) と角度依存吸音 (ADR-0011) との
   併用は solver.log に warning を出して従来の境界に戻す (合っていない壁を
   合っていると偽らない)。
5. **FDTD だけのキー**: 幾何音響はもともとバンド別なので読まない (未知キー
   として無視 — ADR-0003)。それでもキーを `acoustic` 直下に置くのは、
   FDTD が `acoustic.ga` を丸ごと読み飛ばす規約だから (1 つの `.ofdx` を
   両ソルバーで共有する)。吸音性の障害物の面 (ADR-0012) にも同じ規則で効く。
6. **metadata.json は追加キーのみ**: `frequency_dependent_impedance` (bool)、
   `boundary_fd_impedance` (壁ごとの model / status / r / m_s / k_per_s)、
   `geometry_voxels[].fd_impedance` (キーが true のときだけ)。ファイル契約
   (ADR-0007) は不変なのでモックの変更は不要。
7. **ソルバー側の番人** (OpenAcoustics `acoustic_check.sh` の (p)): 準 1D 管の
   端面の |R(f)| をバンド中心の DFT で測り、125 / 500 Hz で √(1−α_b)、
   250 Hz で 1 次素子の閉形式 (awk で独立に解く) と ±3%、metadata の k / m が
   閉形式と ±0.1%、false 指定・帯域内同値は従来とビット一致、実現不能・角度
   依存との併用は warning + 従来とビット一致、障害物の面が外壁とビット一致。

## Consequences

- (+) 既存フローは無変更 (opt-in、キー省略時は従来動作と完全一致)。
  旧版 GUI / 旧版ソルバーとも共存できる (ADR-0003 の未知キー無視)。
- (+) ハイブリッド合成 (ADR-0008) のクロスオーバー付近で、FDTD の壁が
  バンド別の幾何音響の壁に近づく。
- (−) 厳密に合うのは帯域内の 2 バンドだけ。急な吸音特性・共鳴吸音
  (帯域の途中に山がある) は表せない (warning でフォールバック)。
- (−) 角度依存吸音 (ADR-0011) とは併用できない (ランダム入射から ζ を決める
  規則と、バンド別の |R| に合わせる規則が両立しないため)。
