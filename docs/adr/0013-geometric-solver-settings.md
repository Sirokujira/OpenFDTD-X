# ADR-0013: 幾何音響ソルバーの設定 (acoustic.ga) を GUI から書く

## Status

Accepted (2026-10-19) — AcousticSolverTab の「幾何音響ソルバーの設定」→
`AcousticOpts::ga` (GaParams) → `.ofdx` `acoustic.ga`。selftest
`ga-ofdx:` がバイト一致往復・手書きキーの保持・既定に戻した項目の
非復活を検証する。**本 ADR に未実装の項目は無い。**

## Context

- 幾何音響ソルバー (OpenAcoustics の `ofdx_acoustic_ga`) は `.ofdx` の
  `acoustic.ga` から鏡像法の次数・レイ本数・散乱係数 (室の既定)・空気吸収
  (ISO 9613-1 の温度・湿度・気圧)・受音検出球の半径・計算時間を読む。
  FDTD 側は `acoustic.ga` を丸ごと読み飛ばす (1 つの `.ofdx` を両ソルバーで
  共有するための規約)。
- これまで GUI はこのキーを書かず、設定は手書きだけだった。手書きの値は
  未知キー保持 (ADR-0003 案B) で保存しても消えないが、GUI からは見えず
  変えられなかった。

## Decision

1. **`AcousticOpts::ga` (GaParams) で次の 9 項目を扱う**。キー・既定値・
   値域はソルバー (OpenAcoustics ReadMe の `acoustic.ga` 表) と同じ:
   `image_order` (2, 1〜3) / `rays` (30000, 100〜2,000,000) /
   `scattering` (0.1, 0〜1 — 数値のみ) / `air_absorption` (true) /
   `temperature_c` (20, −20〜50) / `humidity_percent` (50, 0〜100) /
   `pressure_kpa` (101.325, 50〜120) / `receiver_radius_m` (自動, 0 < r ≤ 10) /
   `duration_s` (自動, 0 < T ≤ 10)。UI のスピンボックスは同じ値域に縛る
   (範囲外はソルバーが非零終了するため)。
2. **明示した項目だけを書く**。各項目に「ファイルか利用者が明示したか」
   (`has*`) を持ち、明示された項目だけを `acoustic.ga` に書く。全項目が
   未設定なら `ga` キー自体を書かない (旧ファイルとバイト一致 — 絶対規則 2)。
   利用者が既定値に戻した項目は未設定に戻す (キーを書かない)。
3. **利用者が動かした項目だけを反映する**。`apply()` はウィジェットの値が
   表示精度以上に変わった項目だけをモデルへ戻す — 表示の丸めで、手書きの
   細かい値 (例: 20.25 °C) を GUI が勝手に潰さないため。
4. **GUI が扱わない子キーは保持する**: `acoustic.ga.obstacles`
   (幾何音響専用の障害物材質 — 両ソルバーで共有するのは ADR-0012 の
   `acoustic.obstacles`)、`acoustic.ga.angle_dependent_absorption`
   (共有キーは ADR-0011 の `acoustic` 直下)、バンド別の `scattering` 配列は
   GUI では編集せず、未知キー保持 (ADR-0003 案B) が `ga` の中へ書き戻す。
   バンド別配列のときは散乱係数の欄を無効化して理由を表示する。
5. **既定に戻した項目は復活しない**: 未知キー保持の差分は読み込み時点で
   「ファイル − その時点のシリアライズ結果」として計算される。明示された
   項目は読み込み時にシリアライズされるので差分に入らず、後で利用者が
   既定に戻せば保存結果から消える (古い値が差分から書き戻されることは
   ない — ADR-0003 の stale 復活の懸念)。

## Consequences

- (+) 幾何音響の主要な設定を GUI から変えられる。既定のままなら `.ofdx` は
  1 byte も変わらない。
- (+) 手書きの `acoustic.ga` (障害物材質・バンド別散乱など) を GUI で開いて
  保存しても失わない。
- (−) バンド別の散乱係数は GUI では編集できない (室の既定 1 値のみ)。
  必要になったら吸音表と同じ 6 バンド入力を足す。
- (−) これらは幾何音響だけの設定で、FDTD (低域) には効かない。両ソルバーに
  効く設定は ADR-0010/0011/0012 の `acoustic` 直下のキー。
