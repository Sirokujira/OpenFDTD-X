# 未反映設定 (unwired) の棚卸し

GUI の設定フォームには「計算へ反映されない」ものが残っている。本書はその
全件表で、`src/tabs/TabHelpers.h` の 3 種類の明示 (絶対規則 5) のうち
`unwiredNote()` が付いた **82 箇所** を対象にする。

## 3 種類の明示

| 表示 | 意味 | 件数 |
|---|---|---|
| `unwiredNote()` | 設定フォームがどこにも読まれていない | 82 |
| `markNotImplemented()` | ボタンを無効化 (押せない) | 81 (呼び出し 62 箇所。うち 1 件は HDF5 無効ビルドでのみ有効) |
| `sampleNote()` | 表示中の数値が実行結果でないことの明示 | 8 |

## 区分

| 区分 | 意味 | 件数 |
|---|---|---|
| **A** | 表示が古いだけで、実際には配線済み | 0 (下記のとおり解消済み) |
| **B** | `.ofd` に対応キーが無い / ソルバー本体が無い → **カーネル側の作業** | 33 |
| **C** | GUI 層だけで実装できる | 49 |

### A (誤記) について

棚卸しの過程で見つかった A は 2 件で、いずれも `CircuitSolversTab` だった
(「抽出エンジン (PEEC/FEM) の起動は未実装」「ポート定義は計算に渡されません」
と書いてあったが、`runExtraction()` が `peec` / `ofe` を実際に起動していた)。
2026-08-09 の「スミスチャート / S11 表示」の変更で修正済み。

**逆向きの誤記も同じ害がある。** 絶対規則 5 は「未完成を動作済みと見せない」
ことだが、動くものを「未実装」と書けば利用者はその機能に到達できない。
棚卸しは両方向で行うこと。

## 表示の作法 (2026-08-09 に変更)

以前の注記は主語が無く「▸ この設定は現在計算へ反映されません (未実装)」
とだけ出ていた。**節の中に反映される入力と反映されない入力が混在している
場合、利用者は節ごと死んでいると受け取る** (実際にそう報告された)。

現在は主語を必須にしている:

```cpp
tabhelp::unwiredNote(s, I18n::tr("psol_uw_rcwa"), I18n::tr("psol_uw_rcwa_ok"));
// → 「▸ Truncation 法・入射角 (θ, φ, ψ)・TE/TM・出力のチェック —
//     現在計算へ反映されません (未実装)。
//     反映されるもの: 周期・次数・層分割・波長範囲 (.ofdx へ保存されます)」
```

**新しく `unwiredNote()` を足すときは必ず主語のある版を使うこと。**
引数なしの版は既存互換のために残してあるだけで、新規利用は禁止。

## ポスト処理の「どこに出るか」(2026-08-10 更新)

ポスト(1) / ポスト(2) のチェックの出力先は 3 つある。**ev2d / ev3d が無くても
中身が見られる**のは下 2 つ。

| 出力先 | 実体 | 見る場所 |
|---|---|---|
| 作図 | `ev.ev2` / `ev.ev3` / HTML | 中央「カーネル作図」タブ、外部 ev2d/ev3d |
| 2 次元の場マップ | `far2d.log` / `near2d.log` | 中央の 2D 断面 (`CenterPane::loadPostMaps`) |
| 番号付きテキスト表 | `feed.log` / `point.log` / `far0d.log` / `near1d.log` | 結果プロットの「ポスト表」モード |

結果プロットの周波数特性・スミスチャート・放射パターンは `<kernel>.log` と
`far1d.log` から作るので、**ポストのチェックとは無関係**に出る。
